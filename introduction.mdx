## What is dstack?

dstack acts as a unified control plane that sits on top of your GPU infrastructure. Instead of writing provider-specific code or managing Kubernetes manifests directly, you define your workloads in simple YAML configuration files and let dstack handle provisioning, scheduling, networking, and lifecycle management.

## Supported accelerators

dstack works with NVIDIA, AMD, Google TPU, and Tenstorrent accelerators out of the box — and handles GPU detection, driver compatibility, and resource scheduling automatically.

## Get started

<Steps>
  <Step title="Install and launch the server">
    Install dstack with `pip` or `uv` and start the server. See [Installation](/installation).
  </Step>
  <Step title="Configure a backend">
    Connect your cloud provider or Kubernetes cluster by editing `~/.dstack/server/config.yml`. See [Backends](/concepts/backends).
  </Step>
  <Step title="Create a fleet">
    Define a fleet YAML to provision your compute pool. See [Fleets](/concepts/fleets).
  </Step>
  <Step title="Submit a workload">
    Run `dstack apply -f your-config.dstack.yml` to launch a task, service, or dev environment. See [Quickstart](/quickstart).
  </Step>
</Steps>
